# Online Voting System

A web-based voting application developed using PHP and MySQL that allows users to register, authenticate, and cast votes securely through an easy-to-use interface.

## Features

- User Registration
- User Login Authentication
- Secure Voting Process
- Vote Management
- Admin Panel
- Responsive User Interface

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3

## Installation

1. Clone the repository
2. Import the database into MySQL
3. Configure database credentials in db.php
4. Run the project using XAMPP/WAMP
5. Access through localhost

## Purpose

The project demonstrates the implementation of a digital voting platform with authentication and vote processing functionalities.
